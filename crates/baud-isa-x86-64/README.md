# baud-isa-x86-64

**baud's scan with AVX2, on x86-64.**

The AVX2 implementation of `baud-isa`'s operations, held against the portable one by its tests. It is `no_std`.

It is part of [baud](https://github.com/baud-terminal/baud), a terminal emulator, and is one of
the crates baud is built from. Its API follows baud's needs and may change
in any release.
