# `TERM=vt100`

The 1978 DEC terminal every later one extends.

The shared core. Every other profile in this directory overlaps it by ~40 capabilities.

## Status

| | |
|---|---|
| output capabilities | **44** — all handled |
| input capabilities | 22 — **none**; baud has no input path |
| shared with `vt100` | 44 |
| conformance test | `baud-core/tests/conformance/` → `vt100` |
| source | `../../research/sources/terminfo/vt100.ti`, hash-pinned |

Conformance replays every output capability and requires that none is
recognised-and-dropped. Input capabilities are the keys a terminal *sends*;
that half is not implemented and is counted rather than skipped.

A `$TERM` is a capability **profile**, not a protocol — see
[../README.md](../README.md). The protocols this draws on are documented per
level in the parent directory.
