# `TERM=vt52`

DEC's 1975 terminal. **A different protocol, not a subset.**

The only entry here whose sequences *conflict* with the others: `ESC D` is cursor-left, not IND. Reached with `CSI ? 2 l`. See [../vt52.md](../vt52.md).

## Status

| | |
|---|---|
| output capabilities | **17** — all handled |
| input capabilities | 5 — **none**; baud has no input path |
| shared with `vt100` | 16 |
| conformance test | `baud-core/tests/conformance/` → `vt52` |
| source | `../../research/sources/terminfo/vt52.ti`, hash-pinned |

Conformance replays every output capability and requires that none is
recognised-and-dropped. Input capabilities are the keys a terminal *sends*;
that half is not implemented and is counted rather than skipped.

A `$TERM` is a capability **profile**, not a protocol — see
[../README.md](../README.md). The protocols this draws on are documented per
level in the parent directory.
