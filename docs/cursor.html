The cursor trails baud has today

Each clip is baud's own window, captured at up to 120 Hz while a child program jumps the cursor between the four + marks: right, down, left, up, then the two diagonals, 1.15 s apart. Same binary, same 80×24 grid, Menlo at 16 pt, blink off, the system in Dark mode. Only the trail key changes.

Each effect trail is a shader held to a Rust reference, the way fire is. The facts and their sources are in cursor.md.

quad

trail = "quad"

A four-cornered shape whose corners each chase the matching corner of the cursor. The corners facing the move arrive fast and the ones behind it lag, so the shape stretches and snaps shut. The cursor's own cell is left bare.

Lasts
0.36 s for a 30-column jump
From

Timing

sweep

trail = "sweep"

The cursor's box swept from a tail that chases it, fading from nothing at the tail to half the cursor's colour at the cursor. Hard-edged, and the slowest to fold in.

Lasts
0.69 s for a 30-column jump
From

trail = "ghost"

A single cursor-sized box that slides from the cell the cursor left toward the cell it reached, fading as it goes. The quietest of them; at full speed it reads as a flicker, so try ¼×.

Lasts
0.1 s, whatever the distance
From

Timing

What every trail shares

  • A move of two cells or fewer snaps with no trail, so typing never trails. A short move while a trail is still in flight folds it in fast.
  • The cursor has to rest 10 ms at its new place before a trail starts, so streaming output that moves the cursor every read starts none.
  • When a program hides the cursor, a trail that is drawing fades out over 0.4 s instead of vanishing, and comes back if the cursor is shown again. If the screen kept drawing while the cursor was hidden, a trail that starts within 0.4 s of the cursor reappearing starts faint and brightens. Scrolling back into the history, resizing, zooming or switching screens forget where the cursor was.
  • A hidden cursor that a program moves and hides straight away is followed, which is how helix's gg and ge trail.
  • Every trail is drawn in the cursor's colour — the foreground, unless a program sets another with OSC 12. None uses a colour of its own.
  • Under macOS's Reduce Motion the default trail is off. A trail named in the config is kept, fades on a hidden cursor as it does under full motion, and turning the setting on cuts a trail in flight.

Choose one

# ~/.config/baud/config.toml, after every top-level key
[cursor]
trail = "plasma"   # plasma | fire | lightning | ice | ufo | orb | liquid | quad | sweep | ghost | off

true reads as the default (plasma) and false as off. The clips capture only baud's window, so the glass shows as flat dark rather than your wallpaper. Recorded with scripts/trail-clips.sh.
