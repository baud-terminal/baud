Where a fork at launch waits, and what it waits for (note AJ section 20)
=======================================================================

Apple M5 Max, macOS 27.0 (26A5425a), on AC, 2026-10-30. Every probe is a
fresh process, built with clang -O2 -fobjc-arc against Foundation, Metal
and CoreGraphics; times are mach_absolute_time in ms from main's start.
No window was opened.

1. A fork beside the Metal device alone (forkprobe, forkloop)
-------------------------------------------------------------
forkpty at 0.05-10 ms while another thread runs MTLCreateSystemDefaultDevice
(device 8.5-14.8 ms): forkpty took 0.52-1.18 ms at every delay. A loop
forking (fork, child _exit) across the device's creation: 42-53 forks,
worst 0.76-0.96 ms. posix_spawn beside it: 0.17-0.23 ms; with no other
thread: 0.13-0.21 ms (forkpty 0.80-0.97).

2. A fork beside a dlopen (control)
-----------------------------------
A dylib whose constructor spins 50 ms, dlopen'ed on another thread, a fork
started ~0.8 ms in: the fork took 128.45, 50.38 and 50.58 ms (the dlopen
128.8, 50.9, 50.7 ms). A fork waits for the whole of a concurrent dlopen.
MTLCreateSystemDefaultDevice loads two images (DYLD_PRINT_LIBRARIES):
AGXMetalG17X.bundle and IOGPU.framework, both from the shared cache; a
dlopen of the AGX bundle alone took 0.70-0.83 ms.

3. A fork beside the launch's threads (launchlike)
--------------------------------------------------
Threads: NSProcessInfo hostName; a directory walk of the system's font
folders; the Metal device. forkpty 1.5 ms in:
  all three             4.72-26.78 ms (6 runs)
  hostName alone        3.83-29.29 ms (5 runs)
  directory walk alone  0.78-1.10 ms
  Metal device alone    0.84-1.03 ms
  posix_spawn, all three 0.22-1.02 ms
  forkpty 80 ms in, after hostName ended: 1.09-1.52 ms
The device took 21.6-36.0 ms when forkpty was blocked, 10.6-14.2 ms beside
posix_spawn.

4. libc's fork against the kernel's __fork (rawfork, source below)
------------------------------------------------------------------
Forking in a loop while a thread reads hostName, 5 runs an arm:
  fork()    worst 18.48, 27.84, 23.89, 18.36, 27.95 ms
  __fork()  worst 0.26, 0.25, 0.37, 0.26, 0.25 ms
The wait is in user space, before the system call. The same loop
printing every fork over 2 ms (forkloop2), 2 runs: a fork at 5.01 ms took
36.88 (hostName ended at 39.3); forks at 4.49 and 19.66 ms took 14.91 and
12.87 (hostName ended at 20.5).

5. The stack of a blocked fork (whofork, whofork2)
--------------------------------------------------
A watchdog thread suspended the main thread 3 ms into a blocked fork and
walked its frame pointers (three captures, all the same):
  __psynch_mutexwait
  _pthread_mutex_firstfit_lock_wait
  _pthread_mutex_firstfit_lock_slow
  _pthread_atfork_prepare_handlers + 84
  libSystem_atfork_prepare + 32
  fork + 36
With the Metal device on a third thread, its stack at the same moments:
  first:  _os_unfair_lock_lock_slow < pthread_atfork + 76 <
          _dispatch_once_callout < _od_xpc_pipe < _od_running <
          ds_user_byuid < getpwuid < _CFCopyHomeDirURLForUser < ... <
          _CFPreferencesCopyValueWithContainer < _ioSurfaceConnectInternal <
          IOSurfaceClientCopyGPUPolicies < MTLDeviceArrayInitialize <
          MTLCreateSystemDefaultDevice
  later:  _os_unfair_lock_lock_slow < dyld-internal < dlopen <
          _CFBundleDlfcnLoadBundle < -[NSBundle loadAndReturnError:] <
          -[NSBundle classNamed:] < getMetalPluginClassForService <
          -[MTLIOAccelServiceGlobalContext init] < MTLRegisterDevices
The GPU's thread waits on locks the waiting fork holds.

6. Which handler (atforklog, atforktime, source below)
------------------------------------------------------
pthread_atfork registrations, interposed: __cf_atfork_prepare
(CoreFoundation), two with no prepare (libdyld, Heimdal),
_mdns_atfork_prepare (libsystem_info, from __si_module_static_mdns), and
with the device also _od_fork_prepare and _mbr_fork_prepare
(libsystem_info). Each prepare timed, 3 runs: _mdns_atfork_prepare took
32.92; 26.88; 2.66 and 19.77 ms. No other prepare took over 1 ms.

7. baud's order (order, source below)
-------------------------------------
CoreGraphics' display-scale call first, as run() makes it; forkpty about
1.8 ms after it; 8 runs an arm, arms interleaved. as-built: hostName
thread at the start, the device's thread before the fork. hosts-after:
the device's thread before the fork, hostName after. spawn-first: both
after (this probe waits for its child before going on, so its device
starts ~7 ms after the scale; baud does not wait).
  as-built     forkpty 1.22-24.52 ms; device 10.6-48.7 ms
  (an earlier batch of 8: forkpty 2.09-71.19 ms; device 10.2-88.5)
  hosts-after  forkpty 1.60-5.44 ms;  device 8.6-41.5 ms
  spawn-first  forkpty 1.31-4.54 ms;  device 7.1-30.9 ms

Sources read: Libsystem-1356 init.c (libSystem_atfork_prepare: the dlopen
lock first, then the pthread_atfork handlers), libpthread-539.100.4
pthread_atfork.c (_pthread_atfork_prepare_handlers takes
pthread_atfork_lock, then runs each prepare), Libinfo-600 mdns_module.c
(_mdns_atfork_prepare locks _mdns_mutex; _mdns_search holds it across
DNSServiceCreateConnection and the query start) and ds_module.c
(_od_fork_prepare locks the mutex _od_xpc_pipe holds while it makes the
pipe).

---- rawfork.m ----
// fork() against __fork() (the kernel call, no atfork handlers), each
// while a thread reads NSProcessInfo's hostName; the child _exits at once.
#import <Foundation/Foundation.h>
#include <pthread.h>
#include <mach/mach_time.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include <sys/wait.h>
extern pid_t __fork(void);
static double ms(void){static mach_timebase_info_data_t tb; if(!tb.denom) mach_timebase_info(&tb); return (double)mach_absolute_time()*tb.numer/tb.denom/1e6;}
static double t0, he; static volatile int done;
static void *host(void *a){ @autoreleasepool { NSString *h = [[NSProcessInfo processInfo] hostName]; (void)h; } he=ms()-t0; done=1; return 0; }
int main(int argc,char**argv){ int raw=argc>1&&!strcmp(argv[1],"raw"); t0=ms(); pthread_t b; pthread_create(&b,0,host,0);
  double worst=0, at=0; int n=0;
  while(!done){ double a=ms()-t0; pid_t p= raw? __fork() : fork(); if(p==0) _exit(0); double e=ms()-t0; int st; waitpid(p,&st,0); n++; if(e-a>worst){worst=e-a; at=a;} }
  pthread_join(b,0);
  printf("%s: %d forks while hostName ran (%.1f ms), worst %.2f ms at %.2f\n", raw?"__fork":"fork", n, he, worst, at); }

---- atforktime.c ----
// Wraps each pthread_atfork prepare handler to time it.
#include <pthread.h>
#include <dlfcn.h>
#include <stdio.h>
#include <string.h>
#include <mach/mach_time.h>
static double ms(void){static mach_timebase_info_data_t tb; if(!tb.denom) mach_timebase_info(&tb); return (double)mach_absolute_time()*tb.numer/tb.denom/1e6;}
static void (*pre[16])(void); static char nm[16][128];
#define W(i) static void w##i(void){ double a=ms(); pre[i](); double d=ms()-a; if(d>1.0) fprintf(stderr,"prepare %s took %.2f ms\n", nm[i], d); }
W(0) W(1) W(2) W(3) W(4) W(5) W(6) W(7) W(8) W(9) W(10) W(11) W(12) W(13) W(14) W(15)
static void (*ws[16])(void)={w0,w1,w2,w3,w4,w5,w6,w7,w8,w9,w10,w11,w12,w13,w14,w15};
static int n;
static int my_atfork(void (*p)(void), void (*par)(void), void (*chi)(void)){
  if(p && n<16){ int i=n++; pre[i]=p; Dl_info d; if(dladdr((void*)p,&d)&&d.dli_sname) snprintf(nm[i],128,"%s",d.dli_sname); else snprintf(nm[i],128,"%p",p); p=ws[i]; }
  return pthread_atfork(p,par,chi); }
__attribute__((used)) static struct { const void *n, *o; } interposers[] __attribute__((section("__DATA,__interpose"))) = { { (const void*)my_atfork, (const void*)pthread_atfork } };

---- order.m ----
// The launch's order: CoreGraphics' first call (the display's scale), then
// either threads-then-forkpty (as built) or forkpty-then-threads.
#import <Metal/Metal.h>
#import <Foundation/Foundation.h>
#import <CoreGraphics/CoreGraphics.h>
#include <util.h>
#include <pthread.h>
#include <mach/mach_time.h>
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include <sys/wait.h>
static double ms(void){static mach_timebase_info_data_t tb; if(!tb.denom) mach_timebase_info(&tb); return (double)mach_absolute_time()*tb.numer/tb.denom/1e6;}
static double t0, ge, gs;
static void *gpu(void *a){ gs=ms()-t0; id<MTLDevice> d = MTLCreateSystemDefaultDevice(); (void)d; ge=ms()-t0; return 0; }
static void *host(void *a){ @autoreleasepool { NSString *h = [[NSProcessInfo processInfo] hostName]; (void)h; } return 0; }
static double spawn(void){ double s=ms(); struct winsize ws={24,80,0,0}; int m; pid_t p=forkpty(&m,0,0,&ws); if(p==0){ execl("/usr/bin/true","true",(char*)0); _exit(127);} double e=ms(); int st; waitpid(p,&st,0); close(m); return e-s; }
int main(int argc,char**argv){ int first=argc>1&&!strcmp(argv[1],"spawn-first"); int hosts_after=argc>1&&!strcmp(argv[1],"hosts-after"); t0=ms(); pthread_t a,b; double took;
  if(!first && !hosts_after) pthread_create(&b,0,host,0);
  CGDirectDisplayID d=CGMainDisplayID(); CGDisplayModeRef m=CGDisplayCopyDisplayMode(d); double sc=(double)CGDisplayModeGetPixelWidth(m)/CGDisplayModeGetWidth(m); CGDisplayModeRelease(m);
  double scale_at=ms()-t0;
  if(hosts_after){ pthread_create(&a,0,gpu,0); usleep(1800); took=spawn(); pthread_create(&b,0,host,0); }
  else if(!first){ pthread_create(&a,0,gpu,0); usleep(1800); took=spawn(); }
  else { usleep(1800); took=spawn(); pthread_create(&b,0,host,0); pthread_create(&a,0,gpu,0); }
  pthread_join(a,0); pthread_join(b,0);
  printf("%-12s scale %.0fx at %.1f ms; forkpty %.2f ms; device %.1f-%.1f (%.1f)\n", first?"spawn-first":hosts_after?"hosts-after":"as-built", sc, scale_at, took, gs, ge, ge-gs); }
