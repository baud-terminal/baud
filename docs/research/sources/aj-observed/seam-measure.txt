# The launch splash's plasma where one band record meets the next, before and after
# the bands' edges were shared. Before, each band record rounded its own top down and
# its own bottom up, so where the plasma's unit (the block's height at the lockup's
# scale) put an edge between pixel rows, that row was in two records and composited
# twice. After, each edge is rounded once, to the first row whose centre is not above
# it, and shared by the two bands. Measured 2026-10-30 on an Apple M5 Max under macOS
# 27.0, release build, on baud-render's CPU path (the pixels the GPU arms are held to
# by the pixel oracle), with seam_probe.rs; base and change built from one tree.
#
